# WearITReadR

WearITReadR is an open-source Shiny app and R package for generating
codebooks, data dictionaries, and data manuals — paired with a proposed
reporting standard for documenting complex, adaptive study designs
(EMA, ambulatory assessment, JITAIs, and similar).

Modern data collection rarely looks like a paper-and-pencil survey anymore.
Studies today mix passive sensing, adaptive skip/trigger logic, and
per-participant variation in timing and item delivery. Standard reporting
practices haven't kept pace, which makes shared data hard to interpret and
findings hard to reproduce. This site documents both the software we built
to ease that burden, and the standard it's built around.
