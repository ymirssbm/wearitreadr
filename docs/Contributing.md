# Contributing

## Open practices

All materials, code, and data behind WearITReadR and this standard are
open source and publicly available at
[github.com/ymirssbm/wearitreadr](https://github.com/ymirssbm/wearitreadr).

## A collaborative standard

Comprehensive codebooks and data dictionaries for complex, adaptive study
designs are still relatively rare. We think that's mostly down to two
causes: few guidelines currently exist describing documentation needs for
adaptive/complex studies, and thorough documentation is costly — it takes
real, ongoing time investment from research teams, often during the parts
of a study (planning, analysis) when they're busiest.

The [DataDescriptionStandard](standard/) on this site, and the
[JSONSchema](standard/JSONSchema) that implements it, are an initial
attempt at addressing the first problem. WearITReadR itself is an attempt
at the second — using the same technologies that create documentation
complexity (EMA software, cloud computing, adaptive algorithms) to
generate high-quality documentation with minimal added researcher effort.

Both are early and incomplete. We'd like to engage other researchers in
open discussion of the standard described here, and welcome:

- Feedback on the proposed metadata/paradata categories in
  [DataManuals](standard/DataManuals)
- Proposed additions or changes to the [JSON schema](standard/JSONSchema)
- New API translators for other data collection platforms (see
  [WearITReadR](WearITReadR#using-wearitreadr-with-other-data-collection-apps)
  for how the Qualtrics translator was built as a reference example)
- Bug reports and feature requests for the Shiny app and R package

## How to get involved

- Open an issue or pull request on
  [github.com/ymirssbm/wearitreadr](https://github.com/ymirssbm/wearitreadr)
- See the `Examples` folder in the repo for reference implementations to
  build from
